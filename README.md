# My VSCode Plugin 🎲

VSCode 彩票走势图插件 — 支持大乐透、双色球、排列三、排列五的开奖号码走势分析。

## 功能

- 📊 **走势图**：表格化走势图，显示每个位号的开奖号码 + 折线连点
- 🔄 **自动爬取**：内置爬虫，从 500 彩票网抓取开奖数据
- ⏰ **定时更新**：每天 09:30 / 21:35 自动爬取最新数据
- 🎯 **预选行**：在表格底部直接预选号码，支持复式
- 📋 **一键复制**：把预选号码复制到剪贴板
- 📈 **统计分析**：和尾、跨度、奇偶比、012路比

## 安装

### 方式 1：从 .vsix 文件安装

```bash
code --install-extension my-vscode-plugin-0.0.4.vsix
```

或在 VSCode 中：`Ctrl+Shift+P` → `Extensions: Install from VSIX` → 选择 .vsix 文件

### 方式 2：开发模式调试

1. 用 VSCode 打开本项目
2. 按 `F5` 启动调试
3. 在 Extension Development Host 窗口中使用

## 使用

1. **首次使用**：安装后插件会自动爬取数据（约 10-30 秒）
2. **打开走势图**：点击左侧活动栏的彩票球图标 → 点击「📊 打开走势图」
3. **切换彩种**：顶部 TAB 切换 大乐透 / 双色球 / 排列三 / 排列五
4. **切换期数**：下拉选择 50 / 100 / 200 / 500 期
5. **预选号码**：在表格底部的预选行点击号码球（可多选，支持复式）
6. **复制号码**：点「📋 一键复制」按钮
7. **手动刷新**：`Ctrl+Shift+P` → `Refresh Lottery Data`

## 彩种说明

| 彩种 | 位号 | 号码范围 |
|---|---|---|
| 🎲 大乐透 | 前1-前5 + 后1-后2 | 前区 1-35 / 后区 1-12 |
| 🔴 双色球 | 红1-红6 + 蓝 | 红球 1-33 / 蓝球 1-16 |
| 🎯 排列三 | 百/十/个 | 每位 0-9 |
| 🎰 排列五 | 万/千/百/十/个 | 每位 0-9 |

## 数据来源

- 开奖数据来自 [500彩票网](https://datachart.500.com)
- 数据仅供学习参考，与官方开奖无关

## 自动更新

- 插件启动时自动爬取（静默）
- 每天 09:30 和 21:35 自动爬取（需 VSCode 保持运行）
